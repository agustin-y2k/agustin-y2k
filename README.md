### 🚀 Featured project

**[SGRC](https://github.com/agustin-y2k/sgrc)** — Sistema de Gestión y Reserva de Computadoras Educativas. Plataforma web para que una escuela gestione su inventario de PCs y las reserve por curso/materia/horario, con reservas recurrentes, bloqueos por evaluación y reportes de uso. Arquitectura de monolito modular en Go (Fiber) con PostgreSQL, solapamiento de reservas resuelto a nivel de base de datos con `EXCLUDE USING gist`, frontend en React 19 + TypeScript + Vite, y despliegue con Docker Compose detrás de un Cloudflare Tunnel. Cobertura de dominio 94–100% y 253 tests de interfaz con Playwright/Vitest. En producción.
